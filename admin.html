Acesso ao painel

Entre com seu token do GitHub para gerenciar seus produtos.

O token fica somente nesta sessão. Ao sair ou recarregar, será necessário entrar novamente.

Como configurar meu token?
  1. Abra Fine-grained personal access tokens ↗ no GitHub.
  2. Selecione sua conta denardibtw, uma validade curta e somente denardi-resources.
  3. Permita Contents: Read and write. Metadata permanece somente leitura.
  4. Gere o token por conta própria e cole no campo acima. Não envie o código pelo chat.
