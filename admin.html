O token não é salvo no navegador, no backup ou no código da loja.

Como preparar meu acesso?
  1. Abra Fine-grained personal access tokens ↗ no GitHub.
  2. Escolha seu usuário como proprietário, uma validade curta e apenas o repositório denardi-resources.
  3. Em Repository permissions, permita Contents: Read and write. Metadata permanece somente leitura.
  4. Crie o token por conta própria e cole somente neste campo. Não envie o token pelo chat.
